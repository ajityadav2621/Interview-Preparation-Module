# Distributed Tracing

## Definition
Distributed tracing tracks requests as they propagate through multiple services in a distributed system.

## Key Concepts
- **Trace**: Complete request journey
- **Span**: Individual operation within a trace
- **Context**: Trace metadata propagated between services

## Benefits
- Visualize request flows
- Identify bottlenecks
- Debug performance issues
- Understand service dependencies

## Interview Tip
Explain that distributed tracing is essential for debugging microservices architectures where a single request spans multiple services.
