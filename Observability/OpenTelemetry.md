# OpenTelemetry

## What is OpenTelemetry?
A vendor-neutral standard for observability data collection, combining tracing, metrics, and logging.

## Key Features
- **Unified Standard**: Single API for all signals
- **Vendor Neutral**: Works with any backend
- **Auto-instrumentation**: Automatic tracing for common frameworks
- **Context Propagation**: Distributed tracing across services

## Components
- **API**: Application code interface
- **SDK**: Implementation and configuration
- **Collector**: Data processing and export
- **Exporters**: Send data to backends

## Interview Tip
Explain that OpenTelemetry is becoming the industry standard for observability. It's the evolution of individual tracing libraries like Jaeger and Zipkin.
