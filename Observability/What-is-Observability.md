# Observability

## Definition
The ability to understand the internal state of a system through external outputs like metrics, logs, and traces.

## Key Characteristics
- **Queryability**: Ask questions about system behavior
- **Correlation**: Connect different signals across services
- **Debugging**: Understand complex distributed systems
- **Proactive detection**: Identify issues before users notice

## Interview Tip
Explain that observability goes beyond monitoring - it enables debugging of unknown unknowns in complex systems.
