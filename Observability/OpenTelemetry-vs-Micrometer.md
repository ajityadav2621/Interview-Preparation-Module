# OpenTelemetry vs Micrometer

## Micrometer
- **Purpose**: Metrics collection
- **Scope**: JVM and application metrics
- **Integration**: Spring Boot focused
- **Strength**: Simple, lightweight, easy to use

## OpenTelemetry
- **Purpose**: Full observability (metrics, traces, logs)
- **Scope**: Cross-language, cross-framework
- **Integration**: Vendor-neutral standard
- **Strength**: Comprehensive, industry standard

## When to Use Each
- **Micrometer**: Spring Boot applications, metrics-focused
- **OpenTelemetry**: Distributed systems, full observability needs

## Interview Tip
Explain that Micrometer is great for metrics, but OpenTelemetry provides a complete observability solution including traces and logs.
