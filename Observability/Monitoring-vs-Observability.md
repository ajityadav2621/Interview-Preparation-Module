# Monitoring vs Observability

## Monitoring
- **Definition**: Track predefined metrics and thresholds
- **Focus**: Known problems, dashboards, alerts
- **Approach**: What happened?
- **Use Case**: System health, performance tracking

## Observability  
- **Definition**: Explore system behavior through internal signals
- **Focus**: Unknown problems, investigation, debugging
- **Approach**: Why did it happen?
- **Use Case**: Incident response, root cause analysis

## Comparison
| Aspect | Monitoring | Observability |
|--------|------------|---------------|
| Data | Metrics, logs | Metrics, logs, traces |
| Questions | What is happening? | Why is it happening? |
| Setup | Predefined queries | Ad-hoc exploration |
| Value | Proactive detection | Debugging unknown issues |

## Interview Tip
Explain that monitoring tells you something is wrong, while observability helps you understand why it's wrong.
